# 📱 WhatsApp Center

**WhatsApp Center** adalah aplikasi komputer (desktop) yang berfungsi untuk menerima dan mengirim pesan WhatsApp secara otomatis. Aplikasi ini biasanya dipadukan dengan server pulsa, loket pembayaran, atau sistem toko Anda agar transaksi pelanggan dapat diproses secara langsung via WhatsApp.

---

## ✨ Fitur & Keunggulan

- **Otomatis Tanpa Ribet:** Cukup sekali scan kode QR WhatsApp, aplikasi siap mengirim dan membaca pesan 24 jam.
- **Respon Cepat:** Pesan masuk dari pelanggan langsung dibaca dan diteruskan ke sistem transaksi secara instan.
- **Pintar Menutup Pop-up:** Jika WhatsApp menampilkan pop-up informasi/pembaruan fitur, aplikasi akan otomatis menutupnya sendiri agar pengiriman pesan tidak terhenti.
- **Pesan Lancar & Aman:** Mencegah pesan terkirim dobel ke pelanggan dan memastikan pesan susulan dari pelanggan yang sama tidak terlewat.
- **Hemat Ruang Penyimpanan:** Data browser dibersihkan secara cerdas agar tidak memakan ruang hard disk komputer Anda.
- **Bisa Berjalan di Latar Belakang (Unattended):** Dirancang stabil untuk ditinggal menyala terus-menerus tanpa takut aplikasi tiba-tiba macet.

---

## 💻 Kebutuhan Komputer (Spesifikasi Minimum)

Sebelum menggunakan aplikasi ini, pastikan komputer Anda sudah terpasang:
1. **Sistem Operasi:** Windows 7, Windows 8, Windows 10, atau Windows 11.
2. **Google Chrome:** Versi terbaru terpasang di komputer.
3. **Microsoft .NET Framework 4.5.2** (biasanya sudah ada otomatis di Windows modern).
4. **MySQL ODBC Connector** (driver penghubung ke database server Anda).

---

## 🚀 Panduan Penggunaan Singkat

1. **Download & Ekstrak:**  
   Download file `WhatsAppCenter.zip` versi terbaru dari halaman **Releases**, lalu ekstrak file zip tersebut ke folder komputer Anda (misalnya di `D:\WhatsAppCenter\`).
2. **Pengaturan Database:**  
   Pastikan pengaturan koneksi database server Anda sudah sesuai (ikuti panduan dari tim teknis/penyedia server Anda).
3. **Buka Aplikasi:**  
   Jalankan file `WhatsAppCenter.exe`. Jendela Google Chrome WhatsApp Web akan terbuka secara otomatis.
4. **Scan Kode QR:**  
   Buka WhatsApp di HP Anda, masuk ke menu **Perangkat Tertaut** (*Linked Devices*), lalu arahkan kamera ke kode QR yang muncul di layar komputer.
5. **Selesai:**  
   Setelah halaman chat WhatsApp terbuka, status pada aplikasi akan berubah menjadi **Ready**. Aplikasi siap melayani pesan masuk dan keluar secara otomatis!

## ❓ Tanya Jawab & Kendala Umum (FAQ)

- **T: Chrome tidak mau terbuka saat aplikasi dijalankan?**  
  *J:* Pastikan browser Google Chrome di komputer Anda sudah terinstal dengan baik dan tidak ada jendela Chrome sisa sebelumnya yang masih menggantung di Task Manager.
- **T: Mengapa status sering menunjukkan "Browser tidak support"?**  
  *J:* Perbarui Google Chrome di komputer Anda ke versi terbaru melalui menu *Bantuan -> Tentang Google Chrome*.
- **T: Apakah saya perlu scan QR ulang setiap kali aplikasi dibuka?**  
  *J:* Tidak perlu. Selama Anda tidak memilih "Keluar" (*Log out*) dari HP, sesi WhatsApp akan otomatis tersimpan di komputer.
